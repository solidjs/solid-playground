The REPL now runs on Solid 2: hosts need `solid-js` and `@solidjs/web` 2.0, and previews default to the Solid 2 release the package is built against. Solid 1 previews still work with `version="1.9"`. Solid 2 previews load Solid's dev builds, so its diagnostics show in the console, and share one Solid runtime.
